FITON 개인정보처리방침

시행일: 2026년 11월 20일 (이전: 2026년 10월 11일)

FITON(이하 "앱")은 쇼핑몰의 사이즈표와 상품 사진을 캡처해 올리면 내 체형에 맞는 사이즈를 추정해 주는 앱입니다. 앱은 이용자의 개인정보를 가능한 한 적게 다루도록 만들어졌으며, 아래와 같이 처리합니다.

1. 처리하는 정보와 저장 위치

2. 로그인과 서버 저장

  • 로그인하면 위 표의 치수·선호 핏·옷장·입어본 기록·설정과 사진(내 아바타, 옷 상품 사진, 입은 모습 이미지)을 서버(Supabase)의 내 계정 공간에 저장해, 휴대폰과 PC 등 여러 기기에서 같은 내용을 볼 수 있게 합니다.
  • 내 계정 공간은 로그인한 본인만 읽고 쓸 수 있도록 서버에서 막아 두었습니다.
  • 앱에서 옷이나 기록, 사진을 지우면 서버의 내 계정 공간에서도 지워집니다. 로그아웃해도 그 기기에 저장된 자료는 지워지지 않습니다.
  • 예전에 기기 안에만 저장하던 프로필(닉네임+PIN)은 이용자가 "가져오기"를 고를 때만 계정으로 옮겨 담으며, 원래 프로필은 기기에 그대로 남습니다.

3. "AI로 입혀 보기" 사용 시 처리

  • 이용자가 이 기능을 누르면 해당 옷의 상품 사진과 옷 종류, 익명 기기 식별자가 앱의 서버(Supabase 서비스)로 전송됩니다. 옷 치수와 몸 치수의 차이로 계산한 핏 결과도 함께 전송되지만, 키·몸무게·신체 치수 자체는 전송되지 않습니다.
  • 내 아바타를 쓰는 경우에는 그 아바타 사진(얼굴이 포함될 수 있음)도 함께 전송됩니다. 내 아바타를 쓰지 않으면 이용자의 사진은 전송되지 않습니다.
  • 서버는 이 정보를 이미지 생성 서비스(Kling AI)에 전달해 기본 캐릭터 또는 내 아바타가 해당 옷을 입은 이미지를 만듭니다. 전달된 사진은 해당 서비스의 정책에 따라 처리될 수 있습니다.
  • 만들어진 이미지는 이용자의 기기에 저장되며, 로그인한 경우 서버의 내 계정 공간에도 저장됩니다(2번). 이미지 생성을 중계하는 서버 기능은 이미지를 따로 보관하지 않습니다.
  • 생성된 이미지는 AI가 만든 것이며 실제 상품과 다를 수 있습니다. 앱 화면에 "AI 생성 이미지"로 표시됩니다.
  • 서버에 남는 기록은 익명 기기 식별자별 하루 이용 횟수뿐이며, 30일이 지난 기록은 자동으로 삭제됩니다.

4. "아바타 만들기" 사용 시 처리

  • 기본 체형에 내 얼굴을 넣어 아바타를 만드는 경우, 이용자가 화면에서 전송에 동의한 뒤에만 얼굴 사진(고른 네모 안)과 고른 기본 체형, 익명 기기 식별자가 앱의 서버(Supabase 서비스)로 전송됩니다.
  • 서버는 이 얼굴 사진을 이미지 생성 서비스(FASHN)에 전달해 아바타 이미지를 만듭니다. 전달된 사진은 해당 서비스의 정책에 따라 처리될 수 있습니다.
  • 만들어진 아바타 이미지는 이용자의 기기에 저장되며, 로그인한 경우 서버의 내 계정 공간에도 저장됩니다(2번). 아바타 만들기 서버 기능은 얼굴 사진과 아바타 이미지를 따로 보관하지 않습니다.
  • 내 전신 사진을 그대로 아바타로 쓰는 경우에는 만들 때 사진이 전송되지 않고 기기에 저장됩니다. 로그인한 경우에는 내 계정 공간에도 저장됩니다(2번).
  • 서버에 남는 기록은 익명 기기 식별자별 하루 이용 횟수뿐이며, 30일이 지난 기록은 자동으로 삭제됩니다.

5. 외부 서비스

  • Supabase: 회원가입·로그인, 계정별 자료 저장, 이용 횟수 제한과 이미지 생성 요청 중계(서버)
  • Kling AI: 옷을 입은 이미지 생성
  • FASHN: 아바타 이미지 생성
  • 글자 인식 엔진(Tesseract.js): 처음 사용할 때 인식 엔진과 한국어 데이터를 공개 배포망(CDN)에서 내려받습니다. 이용자의 이미지는 전송되지 않고 기기 안에서 처리됩니다.
  • 앱 화면 파일은 GitHub Pages에서 제공됩니다. 접속 시 일반적인 접속 기록(IP 주소 등)이 해당 서비스에 남을 수 있습니다.

6. 보관 기간과 삭제

  • 기기 안에 저장된 정보는 이용자가 직접 삭제하기 전까지 보관됩니다. 앱의 설정 > 고급 > "이 프로필 데이터 지우기"를 누르거나, 앱 데이터(저장소)를 삭제하거나, 앱을 삭제하면 모두 지워집니다.
  • 서버의 익명 이용 기록은 30일 후 자동 삭제됩니다. 이 기록은 이용자를 식별할 수 없습니다.
  • 계정 정보(이메일)와 내 계정 공간의 자료는 계정을 유지하는 동안 보관하며, 이용자가 계정 삭제(탈퇴)를 요청하면 지체 없이 모두 삭제합니다. 계정 삭제는 아래 문의처로 가입한 이메일에서 요청해 주세요.

7. 이용자의 권리

이용자는 언제든지 앱에서 내 정보와 옷장·기록을 열람·수정·삭제할 수 있습니다. 로그인한 이용자는 계정 자료의 열람·삭제와 계정 삭제를 아래 문의처로 요청할 수 있습니다. 개인정보와 관련한 문의나 AI 생성 이미지에 대한 신고도 아래 연락처로 보내 주세요.

8. 아동
